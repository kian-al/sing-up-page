# Sign-Up Form

This repository contains a simple **sign-up form** implemented in Java using **Swing** for the graphical user interface.

## Features
- A graphical **sign-up form** with fields for:
  - Full Name
  - First Address
  - Second Address
  - Age
  - Height
  - Weight
- **Basic validation** to ensure:
  - The full name has at least 3 characters.
  - The two addresses are not the same.
  - Age is above 18.
  - Height is above 100 cm.
  - Weight is above 40 kg.
- **Error handling** to prevent incorrect inputs.
- **Displays user input** in the console upon successful registration.

## Technologies Used
- **Java**
- **Swing (JFrame, JTextField, JButton)**
- **Event Handling (ActionListener)**
- **Basic Data Validation**
